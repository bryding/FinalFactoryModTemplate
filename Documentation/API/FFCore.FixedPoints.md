## FpRailMath

```csharp
public static class FpRailMath
```

Shared fixed-point rail math for the fp movement channels. Lives in FFCore so both FFSystems and tests reach it without duplicating the overflow guards.

| Member | Summary |
|---|---|
| `public static fp MassSpeedFactor(fp mass)` | Deterministic replacement for the transit speed ramp's `math.log10((float)mass + 1)` (platform-variant transcendental — audit Class 2). fp has no log10 (`fpmath.log10` throws), so this derives it as `log2(mass + 1) / log2(10)`, pure fp end-to-end. Negative mass (should not occur) clamps to zero so the log argument stays &gt;= 1. |
| `public static fp RailDistance(fp3 origin, fp3 destination)` | fp is Q31.32: squaring a component magnitude above ~16384 overflows inside `length`. Segments longer than that get scaled down, measured, and scaled back. |
