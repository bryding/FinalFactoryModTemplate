## SimulationRate

```csharp
public static class SimulationRate
```

Rate-independence helpers for simulation behaviour that was written against a heartbeat COUNT instead of simulated seconds. Every helper is pure fp/integer arithmetic on values that are identical on every peer (the fixed step `Dt`, the configured updates-per-second, the deterministic simulation clock), so the result is lockstep-safe.

| Member | Summary |
|---|---|
| `public const int BalanceReferenceUpdatesPerSecond = 60` | The heartbeat rate single-player ran at before 057 US4, which the per-heartbeat balance numbers in the codebase and configs were tuned against. Not the live rate: never use this as `Dt`. |
| `public static int EventsDueAtHeartbeat(int heartbeat, int eventsPerSecond, int updatesPerSecond)` | The heartbeat-counter form of `EventsDueThisStep`, for a cadence that was written as "every Nth heartbeat": `floor(h·r/ups) − floor((h−1)·r/ups)` in exact integers. At the reference rate with `r = 60/N` it reproduces `h % N == 0` exactly; at any other rate it pays out `eventsPerSecond` per simulated second (1 or 2 per heartbeat for 20/s at 16 UPS). |
| `public static int EventsDueThisStep(fp now, fp dt, fp eventsPerSecond)` | How many events a steady schedule of `eventsPerSecond` owes in the fixed step that ended at simulation time `now`: `floor(now·r) − floor((now − dt)·r)`. Stateless (nothing to save), deterministic, and exact over any run of steps — the per-step counts telescope to `floor(now·r)`, so the long-run rate is `eventsPerSecond` at any heartbeat rate. `now` is `FFTimeData.simulationElapsedTime`. |
| `public static fp ReferenceHeartbeatsPerStep(int updatesPerSecond)` | How many reference-rate heartbeats one heartbeat at `updatesPerSecond` spans: exactly 1 at 60 UPS, exactly 3.75 at 16 UPS. Taken from the configured rate (`HeartbeatData.UpdatesPerSecond`, identical on every peer) rather than from `Dt`, because `Dt` at 60 UPS is 2^32/60 truncated and would make the reference rate itself scale by 1 − 2^-28 instead of exactly 1. Returns 1 for a non-positive rate. |
| `public static int ScaleReferenceHeartbeats(int referenceHeartbeats, int updatesPerSecond)` | A heartbeat count tuned at the reference rate (a stride, a phase group), converted to the count that spans the same wall-clock time at `updatesPerSecond`: rounded to nearest, never below 1. 12 at 60 UPS → 3 at 16 UPS. Inputs ≤ 1 stay 1 (run every heartbeat). |
| `public static fp ScaleReferenceProbability(fp referenceProbability, int updatesPerSecond)` | A per-heartbeat probability tuned at the reference rate, rescaled so its expected number of successes per simulated second is unchanged (and so is the mean wait, `dt / p`). Clamped to 1. |
