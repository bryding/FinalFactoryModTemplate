## ProductionStats

```csharp
public struct ProductionStats : IComponentData, IQueryTypeParameter
```

Production stats provides a high-performance way of tracking both production and consumption stats within FF. The underlying structure in production stats is an multi-dimensional array of graphs (both for production and consumption). Data is stored in AtomicCounters, which can be updated in parallel due to C# interlocked access.
