## PlayerColorPalette

```csharp
public static class PlayerColorPalette
```

The default player colours, as 0x00RRGGBB sRGB: feature 079's ten (research R8), then twenty-two more so a game at the lobby cap (`HostJoinPolicy.MaxPlayers`, 32) still gives every player a colour of their own. A player who has not picked a colour gets the first entry no other player in the game uses (`PlayerColorDefaultSystem`).
