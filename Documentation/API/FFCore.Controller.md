## DisposableController

```csharp
public class DisposableController : SingletonMono<DisposableController>
```

This Controller ensures that objects passed to it will be destroyed when the game is stopped including in the editor. On some systems (web/mobile), this may not actually destruct the objects, as the OS sometimes destroys backgrounded processes without giving them a chance to run any shutdown functions.
