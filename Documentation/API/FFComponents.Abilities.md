Pending/consumed intent written by applying one host-completed ability operation exactly once. `CombatProjectileBirthSystem` (Plasma) and the mover-command appliers consume it at `TargetSimulationTimeRaw`; it persists across save/join/recovery until consumed and pruned.

| `public fp3 AimDirection` | Canonical fixed-point aim — raw fp, never a float round-trip. Plasma: the aim direction. ObliteratorDisc: the host-baked displacement from the cast point to the disc's end point. Layout unchanged; only the meaning per kind widened. |
| `public byte Consumed` | 0 = pending, 1 = consumed (kept as provenance until pruned). |
| `public ulong EventSequence` | Completed-operation event sequence; joins the commanded-ship rows below. |
| `public AbilityType Kind` |  |
| `public ushort LeadMilliseconds` | Plasma: the host-baked, clamped shooter lead in milliseconds; the bolt is born at the shooter's simulation position predicted this far ahead (`PlayerFireLead.PredictOrigin`). |
| `public long ReleaseSimulationTimeRaw` | Deterministic release edge for mover-command kinds: target time plus the op-carried duration, in simulation-time raw. The commanded ships' cleanup is gated by THIS value — never by float disc/tracker completion state. |
| `public fp3 TargetLocation` | Canonical fixed-point cast/target location (mover-command kinds). |
| `public long TargetSimulationTimeRaw` | Birth/effect heartbeat as `FFTimeData.simulationElapsedTime` raw. |
