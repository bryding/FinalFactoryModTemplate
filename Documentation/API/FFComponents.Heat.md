## OverheatingState

```csharp
public struct OverheatingState : IComponentData, IQueryTypeParameter
```

Per-structure heat state, derived once per heat pass instead of re-derived by every consumer.

| Member | Summary |
|---|---|
| `public bool IsGlowVisible` | The last glow visibility pushed to `RenderMeshChildren.OverheatingMesh`. Owned exclusively by HeatDamageApplicationSystem -- the grid calculation never touches it -- and exists so that system can skip the transform write when nothing changed. |
| `public bool IsTooHot` | `HeatWarningThresholds.IsTooHot` as of the last heat pass. Written by StationGridCalculationSystem, which is the only thing that moves `CurrentTemperature` at all and does so on one heartbeat in eight -- so this cannot go stale between passes, because the input it is derived from cannot change either. |
| `public bool WillOverheat` | The grid-wide half: the owning grid produces more heat than its installed cooling could ever dissipate, so it is losing the heat fight. Flips for every producer on a station at once, which is why it is never a warning condition on its own -- alone it would light up a whole station of stone-cold structures. |
| `public static float3 GlowParkedPosition { get; }` | Where the glow mesh sits when hidden -- far enough above the structure to be off screen. Lives here rather than as a literal in the two systems that move it so "parked" means one thing. |
| `public static float3 GlowShownPosition { get; }` | Where the glow mesh sits when shown: exactly on the structure it belongs to. |
