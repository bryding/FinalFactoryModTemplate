Lands pending activations on the heartbeat they are due. Main thread and unbursted on purpose: it is idle unless a structure was mined in the last few seconds, and landing one makes structural changes and raises the presentation hook. ## StructureActivation

```csharp
public static class StructureActivation
```

Scheduling and landing of a mined activation (`PendingStructureActivation`). The networked mining completion schedules; `PendingStructureActivationSystem` lands it on the heartbeat the simulation clock reaches the due time. Everything here reads and writes simulation state only; the sound, narration and map label hang off `Completed`.

| Member | Summary |
|---|---|
| `public static Action<Entity, PendingStructureActivation> Completed` | Raised on every peer right after an activation has landed, with the structure and the schedule it carried. Presentation only: the handler must not write simulation state. A throwing handler is logged and swallowed. |
| `public static void Complete(EntityManager em, Entity structure)` | The activation itself: production's writes from after its wait, in the same order. |
| `public static int CompleteDue(EntityManager em, EntityQuery pendingQuery, long simulationTimeRaw)` | Lands every activation whose due time has been reached, in tile order: the rewards are instantiated here, and chunk order is each peer's own load history. |
