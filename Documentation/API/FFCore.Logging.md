## LocalEventJournal

```csharp
public static class LocalEventJournal
```

This peer's own lifecycle moments (pause, save, menu, load, session reset, recovery, frame hitch), each stamped with the (epoch, heartbeat) it happened at, kept in a small ring so a desync report can list what this machine did locally before the verdict. A desync that follows a hitch or a save on one peer and not the other reads straight off that list.

## NetworkOpsTrace

```csharp
public struct NetworkOpsTrace
```

Console-reachable trace keys for logging call sites that live OUTSIDE ECS systems — network operation handlers, the netcode managers, save/load, and the local automation runner. A system-hosted call site keys itself (`Debug.LogTrace(this, …)`); code that is not a system has no such key, so it borrows one of these empty structs instead: `Debug.LogTrace&lt;NetworkOpsTrace&gt;($"…")`.

## TraceRuntime

```csharp
public static class TraceRuntime
```

The Burst-facing half of trace logging: a SharedStatic table of enabled type hashes readable from inside [BurstCompile] jobs. This class deliberately holds NOTHING except the SharedStatic and its read methods so Burst can compile against it; all managed state (name matching, dictionaries, locks) lives in `TraceState`.

## TraceState

```csharp
public static class TraceState
```

Managed control surface for the Trace log level (see the global `Debug` class for the logging API). Tracing is keyed by system/job type: `EnableMatching` uses the same case-insensitive substring RULE as the EnableSystem/DisableSystem console commands, but matches over EVERY compiled system type (the TypeManager registry) rather than only systems instantiated in the current world — so it works befo…

| Member | Summary |
|---|---|
| `public static void DisableAll()` | Turns tracing off for everything. |
| `public static void DisableMatching(string systemName)` | Disables tracing for every currently traced entry whose full name contains the substring. |
| `public static void EnableMatching(string systemName)` | Enables tracing for all systems whose full type name contains the substring (case-insensitive — the same substring rule as the EnableSystem console command, applied over all registered system types) and all non-generic job structs nested within them. |
| `public static void EnableType(Type type)` | Programmatic enable for one specific type (plus its nested job structs) — the escape hatch for types the system-name matching cannot reach. For a standalone (file-scope) job struct, prefer keying the call sites by the owning system type instead (Debug.TraceEnabled&lt;TheSystem&gt;()) so the console commands keep working. |
| `public static void PrintEnabled()` | Prints everything currently being traced. |
