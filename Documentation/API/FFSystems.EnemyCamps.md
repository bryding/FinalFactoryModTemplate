## EnemyCampActivityGate

```csharp
public static class EnemyCampActivityGate
```

The shared player-proximity predicate for the camp lifecycle: the idle cleanup strips spawners from camps OUTSIDE this window (leaving a dormant [Save] shell) and the builder builds/rebuilds only INSIDE it. Both sides MUST use this one predicate — if they ever disagreed, a boundary camp would build and be stripped in an endless loop.
