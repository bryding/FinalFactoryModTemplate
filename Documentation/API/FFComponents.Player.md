## PlayerWreckLifetime

```csharp
public static class PlayerWreckLifetime
```

How long a dead player's wreck stays in the world. The wreck carries a saved `FFComponents.Utils.LimitedLifetime`, which `LimitedLifetimeSystem` advances by the simulation step on every heartbeat, so the hour is an hour of simulated play: time spent paused, in a menu-paused game, or with the save closed does not count. When it runs out the wreck is deleted with everything still in it.

|---|---|

It is read by the `PlayerDefeated` apply, which runs on every peer, so every peer of a session must be given the same value before the death. Never set in a normal game. |
