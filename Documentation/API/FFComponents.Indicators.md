## RangeIndicatorDisplay

```csharp
public struct RangeIndicatorDisplay : IComponentData, IQueryTypeParameter
```

Presentation only — the radii the range rings are currently drawn at, in world units, plus whether they are showing. Deliberately NOT `[Save]`: every value here is recomputed by `RangeIndicatorSystem` from config (or from `ConfiguredRange`) whenever the structure is hovered or selected, so persisting it could only ever preserve a stale answer.
