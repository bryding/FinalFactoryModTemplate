## FFSmoothRigidBodiesGraphicalMotion

```csharp
[UpdateInGroup(typeof(TransformSystemGroup))] [UpdateBefore(typeof(LocalToFFWorldSystem))]
public class FFSmoothRigidBodiesGraphicalMotion : SystemBase
```

A system that can smooth out the motion of rigid bodies if the fixed physics tick rate is slower than the variable graphics framerate. Each affected body's `Unity.Transforms.LocalToWorld` matrix is adjusted before rendering, but its underlying `Unity.Transforms.LocalTransform` component is left alone. THIS IS CUSTOMIZED FROM THE BUILTIN UNITY SYSTEM.
