## EnemyCampInitialStrength

```csharp
[Save]
public struct EnemyCampInitialStrength : IComponentData, IQueryTypeParameter
```

Birth record for a camp placed at chunk generation: the spawner budget from the strength-by-distance curve and the RNG seed for the camp's first (robust) build. The builder consumes these instead of entity-handle/elapsed-time RNG so the initial spawner set is a pure function of (MasterSeed, chunk). Pre-027 camps lack this component and keep the legacy robust-build path.
