## ObjectiveCounterKind

```csharp
public enum ObjectiveCounterKind
```

The "a player did this" counters of `ObjectivesTracker` that the tutorial's objectives read. The numeric values ride the wire (`ObjectiveProgress`) and must not change.

Values: `None = 0`, `FrenzyUsed = 1`, `PlasmaBoltUsed = 2`, `AfterburnerUsed = 3`, `ItemsCollectedFromBuilding = 4`, `MapUsed = 5`, `FleetPanelUsed = 6`, `CopyPastePropertiesUsed = 7`
