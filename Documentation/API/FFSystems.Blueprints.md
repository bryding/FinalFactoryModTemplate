## BlueprintMirror

The integer math of flipping a held blueprint: every value a structure in a blueprint carries that has a handedness, and what it becomes in the mirror image. Pure functions over existing component values, so the held-blueprint flip (`BlueprintFlipSystem`) and its tests share one copy.

## MirrorAxis

```csharp
public enum MirrorAxis
```

Which way a held blueprint is mirrored. `Horizontal` swaps left and right (the mirror line runs up the screen, x changes); `Vertical` swaps top and bottom (z changes). Factorio's names.

Values: `Horizontal = 0`, `Vertical = 1`
