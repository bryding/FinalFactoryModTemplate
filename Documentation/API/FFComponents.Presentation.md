```csharp
public enum WorldEntityInterpolationMode : byte
```

Spec 057 US2 — how a tagged world entity fills the gap between two heartbeat poses. Stored as a byte on `WorldEntityPresentationInterpolation` so the component stays blittable for Burst jobs.

Values: `Interpolate = 0`, `Extrapolate = 1`
