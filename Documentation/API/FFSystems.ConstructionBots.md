## ConstructionBotPoolMode

```csharp
public enum ConstructionBotPoolMode
```

Which bot population a `ConstructionBotPool` pass services. The two were previously separate pool structs (player vs tower); they are now one struct switched by this flag so the claim routine is unified and the genuinely pool-specific bot-discovery / item-sourcing differences are the only branch.

Values: `Player = 0`, `Tower = 1`

## IConstructionBotPool

```csharp
public interface IConstructionBotPool
```

Strategy for one pool of construction bots. A pool decides, for a single construction task, whether it can service the task and — if so — finds an available bot, resolves the item source, and assigns the bot. The shared `ConstructionTaskAssignmentJob{TPool}` owns the deterministic task ordering and iteration; the pool owns the irreducibly pool-specific bot discovery and fulfillment.

| Member | Summary |
|---|---|
| `bool TryProcess(Entity task, ref ConstructionTaskData taskData)` | Attempts to service `task` with this pool's bots. Returns true iff `taskData` was mutated (a bot was assigned, or the task was put on cooldown), signalling the engine to write the task data back. Returns false when this pool does not touch the task (wrong type, on cooldown, already assigned, or no bot found without a cooldown side effect). |
