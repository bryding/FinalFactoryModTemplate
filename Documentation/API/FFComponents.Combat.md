Why a holder's record is or is not usable this heartbeat. ## TargetProgressEvaluator

```csharp
public static class TargetProgressEvaluator
```

The pure give-up decision, kept out of the Burst job so it can be unit tested without the targeting system's singletons. Progress means a new lowest observed health: a heal that is then ground back down part way is not progress, so a regen stalemate still trips the rule.

| Member | Summary |
|---|---|
| `public const int GiveUpAfterSeconds = 30` |  |
| `public const int SkipTargetSeconds = 120` |  |
| `public static void Rebaseline(ref TargetProgressTracker tracker, long currentHealthRaw)` | Raises the low to the target's health now, for a target that healed while this shooter was not shooting it (holding it out of weapon range, or lost and acquired again). The low of an earlier fight would otherwise stand, and shots that land would count as no progress until they wore the whole heal off again. |
| `public static bool Tick(ref TargetProgressTracker tracker, long currentHealthRaw, fp dt, bool firing)` |  |
