## BlueprintFlipCommand

```csharp
public struct BlueprintFlipCommand : IComponentData, IQueryTypeParameter
```

flips of the local player's held blueprint waiting for `BlueprintFlipSystem`, one bit per axis. Each press toggles its bit, so two presses of the same flip before the next heartbeat cancel, exactly as the two flips would. Local and presentation-only, like `RotateCommand`: the flipped ghosts reach the other peers through the placement request, never through this.
