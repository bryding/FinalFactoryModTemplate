## DysonDroneTransit

```csharp
[Save]
public struct DysonDroneTransit : IComponentData, IQueryTypeParameter
```

Fixed-point travel rail for a Dyson drone in `StarSlotNavigationState`. The orbit-slot target is frozen ONCE at the nav-start heartbeat into `Destination` — drones must not chase the live rotator-spun slot per frame, because the per-frame `LinearMotionSystem` integrates wall-clock delta time, making position-per-heartbeat (and therefore the arrival heartbeat) peer-divergent.
