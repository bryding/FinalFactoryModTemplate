## CargoBargeDockTimer

```csharp
[Save]
public struct CargoBargeDockTimer : IComponentData, IQueryTypeParameter
```

How long a cargo barge has been docked at its pickup bay. After InserterPickupSystem.CargoBargeMaxDockSeconds a barge carrying anything departs even if it isn't full. Saved so a joining peer resumes the same countdown as the host; a separate component (not an Inserter field) so saves from before it existed keep the Inserter layout and simply start at 0 from the prefab.
