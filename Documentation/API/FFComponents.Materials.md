## PlayerLiveryColor

```csharp
[MaterialProperty("_ColorAG", -1)]
public struct PlayerLiveryColor : IComponentData, IQueryTypeParameter
```

Per-ship override of the Standard-LowPoly shader's `_ColorAG`: the colour of the region the mask's A.G channel paints, which on `Player.mat` is the blue livery panels. The hull plates (`_ColorAR`), the emissive engine parts and the particles keep the material's values. Linear RGBA, because Entities Graphics uploads a `[MaterialProperty]` value as is and the project renders in linear space.
