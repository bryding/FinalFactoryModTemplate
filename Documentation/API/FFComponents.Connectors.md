## ConnectorGroupUpdateMarker

```csharp
public struct ConnectorGroupUpdateMarker : IComponentData, IQueryTypeParameter
```

This is a marker placed on individual connectors to indicate that the entire group attached to that connector needs to be recalculated. This is not placed on the connector group because the connector group is ephemeral. This will cause the existing group to be deleted and replaced with a new group, attached to all connectors in the group.
