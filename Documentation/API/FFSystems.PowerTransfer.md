## PowerTransferLinks

```csharp
public static class PowerTransferLinks
```

The two halves of a transmitter-to-receiver link: the transmitter's `PowerTransferEdge` names the receiver it targets, the receiver's names the transmitter feeding it. Every writer of the receiver half goes through here, single-threaded, so that a release can never wipe a newer claim.

Re-aims every transmitter when the station grids change. The parallel pass only scans: each transmitter finds the receiver in front of it and writes its OWN edge and alignment. Every change to a receiver's back-link is collected and applied afterwards by one single-threaded job, releases before claims, claims in `PowerTransferLinks.ClaimOrder`.
