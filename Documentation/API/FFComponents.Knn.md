## KnnSourceOrderKey

public struct KnnSourceOrderKey : IComparable<KnnSourceOrderKey>, IEquatable<KnnSourceOrderKey>

A cross-peer total order over the legacy KD-tree's SOURCE population. WHY THIS EXISTS. `KnnSystem.GatherSourcesJob` fills the KD-tree's point array in ECS query iteration order, which is archetype CREATION order — append-only history of how a World was built, not a function of simulation state. A long-running host and a client that restored the same world from a join snapshot never share it.
