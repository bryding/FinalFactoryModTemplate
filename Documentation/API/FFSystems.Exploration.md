Shrinks each trail breadcrumb's fog radius as it ages and enforces `PerformanceSettings.MaxBreadcrumbs`. Breadcrumbs are simulation state (see `BreadcrumbSystem`), so the cap is deterministic and immediate: the newest `MaxBreadcrumbs` crumbs survive, ranked by age and then by position — never by entity order — and every crumb beyond them is marked in the same heartbeat.

## BreadcrumbSystem

```csharp
[UpdateInGroup(typeof(FFFixedPreTransformGroup))]
public struct BreadcrumbSystem : ISystem, ISystemCompilerGenerated
```

Drops a fading breadcrumb behind every player so the fog stays open along the way they came. A breadcrumb is simulation state — it carries a `[Save]`d `FogObserver` and the `census` fingerprint counts it — so the drop is a function of replicated state only: a player drops a crumb when no live crumb occupies the `CellSize`-unit cell its `Player.SimulationPosition` is in.
